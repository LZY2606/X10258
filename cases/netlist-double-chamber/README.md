# 网表双影室：SPICE 子电路展开、参数作用域与连接等价

模拟电路团队导入两份 SPICE 网表（`top_a.sp` / `top_b.sp`）与它们的
include/model 集，审阅展平后的连接、参数与器件语义是否等价。

## 基线（不改写）

导入时原文本、行续接（`+` 续行）、子电路实例、参数表达式（`{wn*2}`）、
model 版本（`.model nch nmos (...)`）、include 来源、单位后缀（`1k`/`1pf`/`1000`）
全部原样保留；规范化只发生在派生层。

## 叙事顺序（case.json）

1. `s01–s02` 导入基线并核对接受；
2. `s03–s05` 一次参数修订（`wp={wn_b*3}`）→ 被否决 → 恢复（未采纳结果保留）；
3. `s06` 一次只影响局部依赖的源数据改动（`wn_b 1u→1.1u`）；
4. `s07` 两位使用者从同一版本做出互相冲突的人工决定 → 可解决冲突；
5. `s09–s21` 边界组合：子电路重名、局部参数覆盖、单位后缀（含不可转换值）、
   循环 include、对称器件置换、未知元件、多个最小差异；
6. `s22–s23` 第二分支：整表 alpha-rename 与“压平表达式依赖”的反例；
7. `s24–s25` 回到等价基线并沿复核路径签收。

## 语义规则

- 节点和实例可 alpha-rename；参数作用域、默认值和表达式依赖不可压平；
- 未知元件保留 opaque 连接而不删除；
- 多解与不确定状态全部保留，不吞掉；
- 重算按依赖图传播，只更新受影响部分，并说明某项结果为何仍有效或为何需要重算。

## 反例档案

每个 `counterexample` 步骤只改动一个直接来源，生成 `archive:*` 条目，
记录判定状态与受影响对象；被采纳与未采纳的结果都保留。
